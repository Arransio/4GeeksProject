## INSTRUCCIONES PREVIAS A CADA COMMIT 
-1. Haz una revision del código a commitear. 
-2. Ejecuta el comando "git fetch". 
-3. Ejecuta "git status" para ver si hay cambios en el repositorio sin traer. Si hay, traelos primero.  
-4. Genera un mensaje de commit de máximo 2 líneas que sintetize el contenido del commit. 
-5. Ejecuta el commit.
